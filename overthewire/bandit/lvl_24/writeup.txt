I began by creating a temporary directory using mktemp -d and changing my working directory to /tmp/tmp.vQ9P4sQIcd. Inside this directory, I wrote a shell script (bd.sh) designed to brute-force the pin code by iterating through every possible four-digit combination (0000 through 9999) using brace expansion and appending each pair of the current level's password and candidate PIN (saved to combinations.txt) to a single file. After making the script executable with chmod 777 bd.sh and running it, I piped the generated combinations to nc localhost 30002 and redirected the responses into resul.txt. To quickly isolate the successful response amidst thousands of failure messages, I ran sort resul.txt | uniq -u, which filtered out all identical failure prompts and revealed the unique string containing the password for Bandit 25
